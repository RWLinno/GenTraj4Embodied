Action sequence policies

Diffusion Policy predicts action sequences with visual conditioning and receding-horizon control. Pose continuity is useful input validation, but this audit does not exercise a policy or environment.

Generalization requires splits

π₀.₅ evaluates generalization to new environments. A distinct filename or unique endpoint is not evidence of a new scene, object, operator or robot. Those identifiers need explicit metadata and split checks.

Data interoperability matters

LeRobotDataset v3 links states, actions, timestamps, video and episode metadata. This tool currently accepts only the documented HDF5 schema; it has no LeRobot adapter or video synchronization audit.

Best use: a small, inspectable data quality tool. A plausible next contribution is a tested adapter plus known-corruption detection benchmarks. A model leaderboard or CCF submission requires substantially more evidence.

Do these files support a multimodal claim?

Repeated endpoints are only a starting point. Group by the full task and scene, sample several outputs per condition, then measure valid coverage. Diversity across unrelated endpoints does not establish conditional multimodality.
